Create a file called journal.md in a new folder, and put it under version control this week (you will learn the
Git workflow properly in Lab 2 — for now, just make the folder and the file).
This journal is the raw material for your 25% retrospective. A retrospective written the night before the
deadline is worth very little and reads like it. A retrospective built from twenty honest weekly entries writes
itself. One short entry per lab is the target — three or four sentences is plenty.
For this lab, after you have played the games below, write an entry answering:
Which game did you find hardest to understand, and was that because of the game or because of the
interface?
Name one thing on screen in any of these games that you think would be difficult to program, and
one that you think would be easy. You do not need to be right — this is about starting to see games as
systems.
Keep it. You will thank yourself in six weeks.
